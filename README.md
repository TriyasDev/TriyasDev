I'm a project leader at heart. I love helping people and teams reach their
goals **efficiently, quickly, and with real impact**. To me, good leadership
isn't about doing more, it's about clearing the path so everyone can move
faster in the right direction.

## Philosophy

**Smart laziness.** Inspired by Linus Torvalds, this isn't about avoiding
work, it's about refusing to do the same work twice. If a task repeats,
I automate it. If a solution can be simple, I won't make it complicated.

**Relentless drive.** Inspired by Nikola Tesla, the time I save isn't spent
idle, it's reinvested in the hard problems: thinking deeply, iterating
tirelessly, and seeing the whole system in my mind before writing the
first line of code.

> Lazy about the repetitive. Relentless about the meaningful.
